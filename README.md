# منصة فلكون للشحن اللوجستي وإدارة البوالص (Falcon Shipping System)

منصة داخلية متكاملة لشركة **فلكون - Falcon** مبنية بأعلى معايير هندسة البرمجيات باللغة العربية (RTL) لإدارة الشحنات، طباعة بوالص الشحن بنقاء عالي على ورق A4، استيراد وتصدير إكسيل ثنائي الاتجاه، والتكامل البرمجي مع منصات الأتمتة (Make.com و n8n).

---

## 🦅 أبرز الميزات والوظائف المكتملة

1. **الواجهة وهوية النظام (Mini Task 1 & 10)**:
   - واجهة عربية كاملة (RTL) بخط Cairo من Google Fonts.
   - شريط جانبي متجاوب يتضمن وصولاً سريعاً لزر `+ إنشاء بوليصة` والـ 8 أقسام التشغيلية.
   - رفع شعار الشركة وحفظه في Supabase Storage (`falcon-assets`) مع دمجه تلقائياً في ترويسة البوالص المطبوعة.

2. **قاعدة البيانات والتحقق المحكم (Mini Task 2)**:
   - نظام PostgreSQL عبر Supabase مع قيود صارمة على المستوى البنكي (`paid_amount <= order_total`).
   - مشغلات تلقائية (Triggers) لمزامنة مبالغ التحصيل وصافي الربح وحالة الدفع فورياً.

3. **إنشاء الطلبات وحسابات الأعمال اللحظية (Mini Task 3)**:
   - حساب فوري لمبلغ التحصيل عند الاستلام: `COD = max(order_total - paid_amount, 0)`.
   - صافي ربح فلكون: `net_profit = order_total - shipping_cost`.
   - تمييز الشحنات المدفوعة بالكامل بختم `مدفوع بالكامل` مع تصفير COD.

4. **نظام استبقاء المسودات الذكي (Mini Task 4)**:
   - حفظ تلقائي للمسودة في التخزين المحلي فور التوقف عن الكتابة (Debounced).
   - استرجاع تلقائي عند انقطاع الاتصال أو إعادة تحميل الصفحة، ومسحها فقط بعد تأكيد الحفظ في السيرفر.

5. **جدول العمليات وتصدير إكسيل (Mini Task 5)**:
   - تصفية متقدمة حسب حالة التسليم، حالة الطباعة، المحافظة، ونطاق التاريخ.
   - تعديل فوري في المكان (Inline Edit) وتحديث جماعي للحالات.
   - تصدير إكسيل للقراءة فقط مع حماية الأصفار جهة اليسار للهواتف المصرية (`010...`).

6. **محرك الطباعة الاحترافي عالي التباين (Mini Task 6)**:
   - مخصص لورق A4 Portrait بتباين أبيض وأسود نقي 100% مناسب لجميع طابعات الليزر والحرارية.
   - نمط 3 بوالص في الصفحة (ارتفاع 91 مم) ونمط 2 بوليصة في الصفحة (ارتفاع 138 مم).
   - خط قص منقط (`✂ قص هنا`) بين البوالص مستثنى من أسفل كل صفحة.
   - تنبيه ذكي لتجاوز كثافة النصوص (Overflow Warning).
   - إدارة طابور الطباعة (`/print/queue`) وأرشيف المطبوعات (`/print/archive`).

7. **معالج استيراد الإكسيل والتوافق الدائري 100% (Mini Task 7)**:
   - محرك مطابق ذاتي للأعمدة يقبل ملفات إكسيل فلكون بضغطة زر دون حاجة لأي مطابقة يدوية.
   - معالجة ذكية لأرقام الهواتف (إعادة الصفر المفقود، تحويل الأرقام الهندية/العربية).
   - تدقيق سطري مع فحص الأخطاء وعزل الصفوف غير الصالحة.

8. **لوحة المؤشرات والمالية ومستحقات شركة الشحن (Mini Task 8)**:
   - لوحة عمليات حية تعرض إجمالي المبيعات، إجمالي التحصيلات (COD)، صافي أرباح فلكون، وعداد قيد الطباعة.
   - جدول تسوية ومطابقة مستحقات شركة الشحن مع كشف حساب إكسيل مالي معتمد.

9. **واجهات الأتمتة (Make.com & n8n Automation APIs) (Mini Task 9)**:
   - مفتاح أتمتة سري معتمد برأس `Authorization: Bearer <API_KEY>` أو `X-API-Key`.
   - حماية كاملة ضد تكرار الطلبات (`Idempotency-Key` Replay Protection).
   - نقاط نهاية RESTful متكاملة لإنشاء الطلبات الفردية والجماعية وتحديث الحالات.
   - دعم الويب هوك الصادر (Outgoing Webhooks) للأحداث الحية.

## 🛠 المتطلبات وبيئة التشغيل

- **Node.js**: إصدار 18.18+ أو 20+ أو 24+
- **Next.js**: 15.2.1 (App Router)
- **Supabase**: مشروع PostgreSQL نشط
- **Tailwind CSS**: 3.4+

---

## 🚀 التشغيل المحلي (Local Development)

```bash
# 1. تثبيت الحزم
npm install

# 2. إعداد متغيرات البيئة
cp .env.example .env.local
# قم بملء مفاتيح Supabase داخل .env.local

# 3. تشغيل خادم التطوير
npm run dev
```

افتح المتصفح على: `http://localhost:3000`

## 🌐 النشر على Vercel (Production Deployment)

1. اربط مستودع المشروع بحساب Vercel.
2. اضبط متغيرات البيئة التالية في لوحة تحكم Vercel:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `AUTOMATION_API_KEY`
   - `NEXT_PUBLIC_APP_URL`
3. إعداد أمر البناء: `npm run build`.
4. انقر على **Deploy**.
